## 📚 Tópicos Abordados

### 1. Fundamentos de Banco de Dados
- Conceitos de dados, informação e banco de dados
- Sistemas Gerenciadores de Banco de Dados (SGBD)
- Modelos de dados: hierárquico, relacional e orientado a objetos
- Arquitetura de três esquemas (externo, conceitual, interno)

### 2. Modelagem de Dados
- **Modelo Entidade-Relacionamento (ER)** — entidades, atributos e relacionamentos
- **Diagrama ER (DER)** — representação gráfica do modelo
- Cardinalidade: 1:1, 1:N e N:M
- Normalização: 1FN, 2FN e 3FN

### 3. SQL — Structured Query Language
- **DDL** — `CREATE`, `ALTER`, `DROP` (definição de estruturas)
- **DML** — `INSERT`, `UPDATE`, `DELETE` (manipulação de dados)
- **DQL** — `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`
- **DCL** — `GRANT`, `REVOKE` (controle de acesso)
- **Joins** — `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`

### 4. Transações e Controle de Concorrência
- Propriedades ACID: Atomicidade, Consistência, Isolamento e Durabilidade
- Controle de concorrência: bloqueios e deadlocks
- Níveis de isolamento de transações
- `COMMIT`, `ROLLBACK` e `SAVEPOINT`

### 5. Banco de Dados NoSQL
- Diferenças entre SQL e NoSQL
- Tipos: chave-valor, documentos, colunar e grafos
- Casos de uso e vantagens do NoSQL
- Introdução ao MongoDB e Redis
